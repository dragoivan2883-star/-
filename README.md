# Прототип Agenta: направление на ремонт

Локальная демонстрационная модель кабинета страхового агента. В ней можно посмотреть утверждённый рекламный баннер, создать тестовую заявку на ремонт и найти её в отдельном реестре. Прототип **не подключается к рабочему сайту или API Agenta**. Используйте только вымышленные данные.

## Запуск

Нужны Node.js 24 и pnpm. В корне проекта выполните:

```powershell
pnpm install
pnpm dev
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Сервер принимает соединения только с локального компьютера. Для проверки сборки и сценария работы:

```powershell
pnpm build
pnpm test
```

Заявки и время закрытия баннера сохраняются в SQLite-файле `data/prototype.sqlite`. Каталог `data/` исключён из Git. При повторном запуске существующие тестовые заявки остаются на месте. Чтобы использовать отдельную базу, задайте переменную окружения `DATA_DIR` перед запуском.

## Что можно проверить

- Выберите «Демо: Агент 1», «Демо: Агент 2» или «Демо: Администратор». Это выбор демонстрационной роли, **не настоящая авторизация**.
- На входе агенту без заявок показывается модальное окно. После закрытия оно может появиться снова при следующем входе не раньше чем через 48 часов. После первой заявки этого агента автоматический показ прекращается.
- На главной в локальном режиме есть кнопка «Тестировать баннер». Она открывает [утверждённое изображение](public/banner-approved.png) для просмотра, не меняя время закрытия и данные заявок.
- Нарисованные на изображении «Х» и «Направить на ремонт» работают как кнопки. Клик вне окна и Esc его не закрывают.
- Постоянная кнопка в верхней панели ведёт к форме. Заявка с данными клиента, автомобиля и повреждений сохраняется в локальной базе.
- В реестре есть поиск, фильтр по статусу и просмотр карточки. Агенту сервер отдаёт только его заявки; администратору — все.

## Устройство проекта

| Путь | Назначение |
| --- | --- |
| `src/` | Vue 3: страницы, маршруты и стили интерфейса. |
| `server/server.mjs` | Локальный HTTP API, демонстрационные сессии и SQLite. |
| `public/banner-approved.png` | Исходный утверждённый баннер без изменений. |
| `tests/smoke.test.mjs` | Проверка правил показа, ролей и сохранения после перезапуска. |
| `SITE_ANALYSIS.md` | Наблюдения по действующему кабинету. |
| `PLAN.md` | Согласованные требования и этапы. |

## Граница текущего этапа

Администратор пока просматривает заявки. Изменение статуса, назначение ответственного и комментарии предусмотрены следующим этапом в [PLAN.md](PLAN.md). Демонстрационный выбор роли не защищает данные при публикации в сети, поэтому прототип предназначен только для локального запуска.
